# Cognitive Sentinel

A simple AI system for cleaning noisy Arabic social media text and applying classical search algorithms.

## Project Overview
This project loads a Facebook-exported dataset, extracts Arabic text, cleans and normalizes it, and produces a structured dataset. After cleaning, the system applies BFS, DFS, and A* search on the dataset index.

## Main Features
- Extract Arabic text from mixed content
- Normalize Arabic letters
- Remove emojis, symbols, and diacritics
- Clean repeated characters and spacing
- Build a final structured dataset
- Implement BFS, DFS, and A* search
